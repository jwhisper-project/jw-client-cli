JWhisper Client CLI Overview

The jw-client-cli artifact is the terminal-facing interface for JWhisper end-users. It manages the full lifecycle of identity profiles, handles background network I/O, and executes the cryptographic client-side operations necessary to maintain true End-to-End Encryption (E2EE).

Key Structural Pillars

  • io.github.artshp.jwhisper.client.cli.users: Contains information about other users to be able to encrypt messages for them and verify message from them.
  • io.github.artshp.jwhisper.client.cli.network: Maintains full-duplex TCP/IP loops utilizing an unblocking dual-track network state configuration (segregating asynchronous incoming packet listeners from interactive typing loops).
  • io.github.artshp.jwhisper.client.cli.security: Powers the localized Hybrid Cryptosystem. Handles local secure key storage inside PKCS12 structures, signs transmissions with Ed25519 identities and encrypts them with X25519 per-message keys.
